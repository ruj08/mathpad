Type math like you'd text it

Make a line math with Ctrl+M, the ∑ button, or by starting it with $$. In normal text, wrap math in $…$. Click an example to add it to your note.
Keys
Enter new line (math stays math)
Enter on an empty math line → back to text
Shift+Enter line break inside a block
Ctrl/⌘+M switch text ↔ math
↑ ↓ move between lines
Start a math line with = to line it up under the line above.

Formatting (same shortcuts as Google Docs)
Ctrl+B bold · Ctrl+I italic · Ctrl+U underline
Alt+Shift+5 strikethrough
Ctrl+Alt+1–3 headings, 0 normal text
Ctrl+Shift+L / E / R left / center / right
Ctrl+Shift+. / , bigger / smaller
Ctrl+Shift+8 bullets · 7 numbers
You can also type the marks yourself: **bold** *italic* __underline__ ~~strike~~ ==highlight== # Heading - bullet, plus labels like Definition:, Theorem:, Proof:
Escape hatch: anything starting with \ is passed to LaTeX as-is, e.g. \mathcal{L}. Quotes make words: "area" = l w.
